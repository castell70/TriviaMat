Ayuda detallada

Bienvenido a MathTrivia — una aplicación para practicar y evaluar habilidades matemáticas por categorías.

  1. Registro: Escribe tu nombre en el panel izquierdo y presiona "Iniciar juego". El nombre se usará para guardar tu historial.
  2. Seleccionar categoría: Toca una categoría en la lista izquierda; el contador entre paréntesis muestra cuántas preguntas hay disponibles.
  3. Inicio de la ronda: Cada ronda toma hasta 10 preguntas aleatorias de la categoría seleccionada. Las opciones de cada pregunta se barajan en cada intento.
  4. Responder: Toca la opción que consideres correcta. La aplicación indicará inmediatamente si la respuesta fue correcta (verde) o incorrecta (rojo) y mostrará la respuesta correcta si aplica.
  5. Consejos: Después de una respuesta incorrecta verás un consejo breve para esa pregunta; además en la columna izquierda aparece un consejo general para la categoría seleccionada.
  6. Progreso y puntaje: El encabezado muestra la pregunta actual y el puntaje se actualiza en tiempo real en la esquina inferior derecha del área de juego.
  7. Siguiente: El juego avanza automáticamente tras mostrar el resultado; también puedes usar el botón "Siguiente" si necesitas saltar manualmente.
  8. Historial: Al finalizar la ronda el resultado se guarda en el historial del jugador. Pulsa "Historial" en la barra superior para ver intentos previos por jugador y categoría.
  9. Cargar preguntas: Usa "Cargar más preguntas (JSON)" para añadir preguntas desde un archivo con la misma estructura que el archivo integrado (categorías con listas de objetos {question, options, answer, tip}).
  10. Exportar: "Descargar preguntas (JSON)" exporta la base de preguntas actualmente cargada para compartir o backup.
  11. Ejemplo: Pulsa "Pregunta de ejemplo" para ver el formato de una pregunta de demostración.
  12. Privacidad: Los historiales se almacenan localmente en tu navegador (localStorage) y no se envían a servidores externos.
